# 마실

누워서 가는 트리 명소. 방에서 픽셀 캐릭터로 크리스마스 트리 명소를 돌아다니고, 옷을 갈아입고, 사진을 찍는 웹 서비스입니다.

## 할 수 있는 것

- **명소 6곳 구경**: 여의도 더현대, 삼성 별마당 도서관, 잠실 롯데월드몰, 명동 롯데백화점, 명동 신세계백화점, 영종 파라다이스시티
- **캐릭터 만들기**: 처음 들어오면 헤어 → 얼굴 → 옷 → 모자 → 소품 → 이름 순서로 직접 고릅니다.
- **옷장**: 가진 아이템을 입어 보고 "이대로 입기"로 저장합니다. 아직 안 열린 아이템은 공개 날짜가 보입니다.
- **선물 달력**: 11/15부터 12/25까지 하루에 하나씩 새 아이템이 열립니다 (41개).
- **카운트다운 전광판**: 장면 안에 크리스마스까지 남은 시간이 걸려 있습니다.
- **사진 찍기**: 1080×1920 폴라로이드 사진으로 저장합니다. 이름표, 장소, D-day가 함께 찍힙니다.

휴대폰에서는 한 줄로, 넓은 화면에서는 왼쪽에 광장·오른쪽에 메뉴가 놓입니다.

## 시작하기

```bash
npm install
npm run dev
```

| 명령 | 하는 일 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm run build` | 타입 검사 후 `dist/`에 빌드 |
| `npm test` | 단위 테스트 (Vitest) |

주소 끝에 `?date=2026-12-24`를 붙이면 그날 밤 9시로 시간을 옮겨 선물 달력과 카운트다운을 미리 볼 수 있습니다.

## 구조

```
src/
  engine/     픽셀 캔버스 도구(원근 벽·바닥, 빛 번짐)와 공용 소품(트리, 부스, 가로등…)
  scenes/     명소별 배경. 장소 하나가 파일 하나
  avatar/     꾸미기 항목(options)과 2등신 아바타 그리기(draw)
  advent/     선물 달력 일정과 날짜 계산 (한국 시간 기준)
  game/       광장 상태(world), 카운트다운 전광판(board), 사진(photo)
  components/ React 화면: 광장, 옷장, 캐릭터 만들기, 선물 달력, 창들
  lib/        저장소, 이름 확인
```

모든 장면은 270×480 저해상도 캔버스에 코드로 그린 뒤 화면에서 확대합니다. 배경은 장소마다 한 번만 그려 두고, 전구 깜빡임·눈·캐릭터만 매 프레임 그립니다.

## 알아 둘 점

- 이름, 옷, 열어 둔 선물은 이 기기 브라우저(localStorage)에만 저장됩니다.
- 다른 방문자 캐릭터는 아직 실제 사용자가 아니라 시연용으로 움직입니다.
- 장면은 실제 명소의 공간 구조와 분위기를 참고해 새로 그린 픽셀 그림이며, 각 장소·회사와 관계없는 비공식 프로젝트입니다.
